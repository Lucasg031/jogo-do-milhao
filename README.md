
# 🎮 Jogo do Milhão

## 📖 Sobre o Projeto

O Jogo do Milhão é um jogo de perguntas e respostas desenvolvido para a web, inspirado no formato de programas de perguntas e respostas.

O objetivo é responder corretamente a 16 perguntas e conquistar o prêmio fictício de R$ 1.000.000.

## 🚀 Funcionalidades

- Menu principal interativo.
- Escolha de dificuldade: Fácil, Médio, Difícil e Extremo.
- Perguntas e respostas em português brasileiro.
- Quatro alternativas por pergunta.
- Cronômetro de 60 segundos.
- Sistema de premiação progressiva.
- Registro do maior prêmio no navegador.
- Animação de vitória com dinheiro caindo.
- Layout adaptável para celulares e computadores.

## 🛠️ Tecnologias Utilizadas

- HTML5
- CSS3
- JavaScript

## 🎯 Como Jogar

1. Clique em "Iniciar".
2. Leia a pergunta apresentada na tela.
3. Escolha uma das quatro alternativas.
4. Acerte para avançar e aumentar o prêmio.
5. Responda corretamente às 16 perguntas para ganhar o milhão fictício.

## 📂 Estrutura do Projeto

- `index.html` — Código principal do jogo.
- `README.md` — Documentação do projeto.

## 🌐 Como Executar

1. Baixe os arquivos do projeto.
2. Abra a pasta no VS Code.
3. Execute `index.html` utilizando o Live Server ou abra o arquivo no navegador.

## 📌 Observações

O jogo utiliza dinheiro fictício e não oferece premiações em dinheiro real.

As perguntas são selecionadas de um banco local em português.
